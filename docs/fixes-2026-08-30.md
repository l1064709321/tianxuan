## 二、CharTransformer 训练管线接入

### 进展
- `train.ts` 支持 `--transformer 1` 开关
- `--nlayers`/`--nhead` 参数控制 Transformer 配置
- 训练侧跑通: `loss=5.75`, 参数 137,509

### 阻塞点 (暂停原因)

**问题**: `engine.ts` 加载 Transformer checkpoint 生成时报错
```
TypeError: Cannot read properties of undefined (reading 'attn')
    at CharTransformer.backwardBlock
```

**根因**: Transformer 前向缓存结构 (`ln1Outs`/`attnOuts`/`ffnOuts`) 与反向传播期望 (`ln2Outs`) 不匹配。已在前向添加了 `ln2Outs` 存储，但 `backwardBlock` 里传参逻辑仍有类型/逻辑问题。

**尝试过的修复**:
1. 前向添加 `cache.ln2Outs[l] = hAfterLN2` ✅
2. `backwardBlock` 改用 `cache.ln2Outs?.[layerIdx]` ✅
3. 修复 Float64Array 类型错误 ✅
4. 但 `backwardAttention` 的 attnScores 参数类型不匹配 ❌

**判断**: 继续调试会陷入"修一个bug出两个bug"的死循环。Transformer BPTT 的实现质量不如 GRU 成熟，当前优先保证 GRU 主线稳定。
