# 天玄诊断报告: Attention 神经泛化失败 → 根因修复(2026-08-11, 终版)

状态: 已完成定位与修复; 梯度检查全绿; 证据门槛未达成(attention 保持货架)。

## 1. 原现象(修复前)

| 模型 | 训练 loss | 验证 loss | 验证 top-1 | maxProb 均值 |
|---|---:|---:|---:|---:|
| 纯 GRU(depth 2, 坏内核) | 1.31 | 1.313 | 48.5% | 0.511 |
| GRU + Attention(旧接入) | 1.36 | 4.405 | 0.9% | 0.090 |

现象本质: 训练 loss 正常, 验证输出接近均匀分布("自信地错"), 比随机还差。
初步结论(旧版报告): "接入位置错误 + 任务不匹配"。

## 2. 根因(本轮全部定位, 由梯度检查逐项逼出)

1. **GRU 候选态前向漏掉重置门(最严重)**: `ac += uc[k]*hPrev[k]` 应为 `uc[k]*(r[k]*hPrev[k])`。
   后向却按带 r 的标准 GRU 计算 → 前反向不一致, 重置门在前向"死掉", 整个内核在优化一个
   与真实函数不一致的梯度。旧基线 48.5% 就是坏内核训出来的。
2. **cell1 循环梯度被覆盖**: BPTT 反向里 `dH1Next[j] = dH1[j]` 应为 `+=`, 丢掉了
   h1_{t+1}→h1_t 的时间链梯度(cell2 路径写对了, cell1 漏了)。
3. **Attention 缺跨时刻 hist 反向**: 未来时刻把 h2_t 当 K/V 输入, 梯度从未回传到 h2_t;
   且 RMS 归一化的雅可比被整体跳过 → 分析梯度与数值梯度系统性不符。
4. **Attention 接入位置**: 旧实现把 attention 加到输出端旁路, 梯度被深层稀释;
   已改为层内调制: attnOut 汇入 cell2 输入 x2 = h1 + gate·context(gate 由当前 h1 学习)。
5. **推理/训练路径错位**: `step()` 的 `if (depth === 2)` 在 depth=3 跳过 cell2;
   `state.hist.slice(0,-1)` 与训练 hist 差一位; 训练 hist 长度 ctx-1 vs 推理 ctx(off-by-one)。
6. **AssocCorpus 生成器 bug**: 干扰三元组用 `key[1]/key[2]`(人名第二字+动词)而非抽取的
   动词/宾语 → 干扰句全是乱码, 任务本身不可学(已修复并新增单字人名强任务 RecallCorpus)。

## 3. 修复后验证(沙箱)

- 梯度检查(中心差分, eps=1e-4, T=9/ctx=8, 全路径): attnQ/K/V/GW/GB、out、cell1/cell2、
  emb 全部 relErr=0.0000。纯 GRU 在 T=2..9 全部 0.0000。**反向数学现在完全正确**。
- 事件语料(30k, 2ep): 修复后基线 49.1% top-1; GRU+Attention 47.8%(旧版 0.9% 崩塌消失)。
  Attention 不再损害模型。
- 生成: 正常产出事件文本, 路由 L3/L2 混合, 平均置信 ≈ 基线。
- Gate 选择性(探针): 事件语料上双峰分布(<0.2 关 36.7%, >0.8 开 42.2%)——能学"开关"。
  recall 任务上 gate 100% 关闭(均值 0.004)——拿不到收益时学会关停, 非强制干扰。

## 4. 证据门槛: Attention 尚未 enabled(保持货架)

为验证「attention 擅长的任务」构造了两个跨位置召回语料:
- AssocCorpus(双字人名, 目标动词可被"最近动词"启发式蒙对) → 两模型都 ~17%(≈启发式)。
- RecallCorpus v2(单字人名, 干扰句动词≠目标动词, 最近启发式=0%):
  60k 字符 × 4 轮, hidden 96: GRU 就后召回 15.4%, Attention 10.5%(随机 12.5%)。

**点火探针(Ignition Index 思路)**: 在"X就"处 attention 权重 argmax 落在句首目标位置
(hist 下标 3)的比例高(样本中 ~60%+), 说明"往哪看"学对了; 但 gate 全关 + 取值解码
(hidden 96 / 6 万字符级)无法把点火转化为准确率 → 端到端召回未形成。

结论: **机制正确、选择性真实、不损害基线; 但在当前算力/规模下无法给出
"attention 修复了某指标缺口"的证据 → 按宪章第 7 条保持 shelf, 不得 enabled。**
后续: 提高容量/语料后重试 recall 证据任务; 或转 Mamba(快动力学)/Titans(记忆)按各自
证据路径推进。

## 5. 遗留风险

- attention 训练成本随 ctx 线性涨(ctx=16 时 60k×4ep ≈ 25min CPU), 大 ctx 需重估。
- 就后召回探针已修正 off-by-one(fw[t] 预测 chars[t+1], 条件应为 chars[t]===就)。
